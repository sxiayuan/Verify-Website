Welcome to the Verify Website read me page! I am very excited to share my experience and walk you through my coding process -- let's go!

00 Project Inspiration & Motiviation 
I am building this website to create a landing page for my own desktop app, Verify, which is a lightweight cross-platofrm assitant that verifies highlighted texts through efficiency LLM models (currently only offering OpenAI's GPT model). This website will introduce the app to it's consumers giving it a concrete breakdown from it's functions to pricing. It will be the tunnel that connects all social media platforms and founder of the app (including contact us, Instagram, Github, FAQs etc.). 

01 Project detials 
This project is made on VSCode with programming languages HTML for the basic structure, CSS for the styling, design and some transitions and finally javascript for it's interactivity and modern/chic look. 
The website is hosted on Github pages and all the code is published onto Github Repo for public view. 

02 Project challenges and growth
I have seen a massive improvement since my last website. Although I am still learning the coding languages, I can see my experiences building. I have become very familar with styling in css and getting the core of the website down with HTML. However, creating transitions with Javaascript and CSS have been a struggle and a learning curve for me. I got help from a lot of my friends who know how to code through coding sessions and online resources. 
One specific thing I learned that I will carry with me for the rest of my projects is the use of SVG icons from websities instead of using internet images with transparent backgrounds, which is what I used for previous websities. 
This website helped me think outside of the box and from the perspective of the auidence/user instead of just the programmer's perpsective. I thought of creative ways to engage the viewer and have a balance of information throughout the website. A lot of the contact us pages have not been completed yet as the information still isn't avaliable. That will be a next step. 
I found incoporating the video (which was new to me), figuring out the spaciing of the blocks and creating transitions to be challenges that I still need to work and improve on.

Despite all the struggles, I'm satisfied with my end product and have grew a lot on this journey.
